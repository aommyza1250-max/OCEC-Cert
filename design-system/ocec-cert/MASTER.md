# OCEC Cert — Design System (Master)

ที่มา: ui-ux-pro-max v2.13.0 — ผลค้นจาก `--domain product`, `--domain style`,
`--domain color`, `--domain typography`, `--domain google-fonts`, `--domain ux`
(ไม่ได้ใช้ผลรวมจาก `--design-system` เพราะมันเลือกสไตล์ Exaggerated Minimalism /
ฟอนต์ละตินแบบนิตยสาร ซึ่งไม่ตรงกับหน้าเว็บภาษาไทยที่ต้องเน้นการเข้าถึง — ดูหมายเหตุท้ายไฟล์)

## ผู้ใช้และเป้าหมาย

ผู้ใช้หลักของหน้าสาธารณะคือ **ผู้ปกครอง** ส่วนใหญ่ไม่คุ้นเว็บ ใช้บนมือถือ เข้ามาทำงานเดียว:
หาเกียรติบัตรของลูกแล้วเก็บไฟล์ ทุกการตัดสินใจด้านดีไซน์ตัดสินจากข้อนี้ก่อน

## Product pattern

`Government Portal / Civic Services` → **Service Directory + Search**
ช่องค้นหาคือ CTA เดียวของหน้า ไม่มีเมนู ไม่มีอะไรให้เลือกก่อนค้น

## Style

1. **Accessible & Ethical** (หลัก) — WCAG AAA, ตัวหนังสือ 16px+, focus ring 3px,
   touch target 44×44px, semantic HTML, รองรับ `prefers-reduced-motion`
2. **Trust & Authority** (รอง) — ป้ายรางวัล/เหรียญเป็นตัวเอกของการ์ด

## Color tokens (`apps/web/src/app/globals.css`)

| บทบาท | ค่า | ใช้กับ |
|---|---|---|
| `--color-brand` | `#1E40AF` | ทุกอย่างที่กดได้ + หัวเรื่อง (บนขาว 8.4:1) |
| `--color-brand-dark` | `#172554` | hover ของปุ่ม, แถบทับรูป |
| `--color-brand-soft` / `-line` | `#EFF6FF` / `#BFDBFE` | พื้นอ่อน, เส้นขอบ |
| `--color-flag-red` | `#C81E1E` | ตราสัญลักษณ์ + ข้อความเตือน (5.9:1) |
| `--color-flag-yellow` | `#FACC15` | แถบตราสัญลักษณ์เท่านั้น **ห้ามใช้เป็นสีตัวอักษร** |
| `--color-ink` / `-soft` | `#0F172A` / `#475569` | ตัวหนังสือ (15.8:1 / 7.4:1) |
| `--color-paper` / `--color-card` | `#F8FAFC` / `#FFFFFF` | พื้นหน้า / พื้นการ์ด |

**กฎการใช้สี:** น้ำเงิน = กดได้, เหลือง = รางวัล/ไฮไลต์, แดง = ตราสัญลักษณ์+คำเตือน
ห้ามสลับ ไม่งั้นผู้ใช้เดาไม่ออกว่าอะไรกดได้

สีรายรางวัล (`--color-{gold,silver,bronze,merit,perfect}-{bg,ink,line}`) ทุกคู่ผ่าน AA
และป้ายรางวัลต้องมี **ข้อความ + ไอคอน** กำกับเสมอ ห้ามสื่อความหมายด้วยสีอย่างเดียว

## Typography

`Noto Sans Thai Looped` (400/500/600/700) โหลดผ่าน `next/font/google` → self-host
เลือกแบบ **มีหัว** เพราะเป็นแบบเดียวกับหนังสือเรียนไทย อ่านง่ายที่สุดสำหรับคนทั่วไป
ขนาดตัวอักษรพื้นฐาน **17px** (ไม่ใช่ 16px) เพราะผู้ใช้หลายคนสายตายาว

## Layout / density

คอลัมน์เดียว กว้างสุด `max-w-5xl` การ์ดเกียรติบัตรเป็นกริด 1 / 2 / 3 คอลัมน์
ระยะห่างระดับ standard (16–64px) ปุ่มหลักสูง 48–56px

## Motion

CSS transition 200ms กับ hover/active เท่านั้น **ไม่ใช้ GSAP หรือ scroll animation**
บนหน้านี้ — เพิ่มน้ำหนักให้หน้าที่ต้องเปิดพร้อมกัน 300–500 คนโดยไม่ช่วยให้ใช้ง่ายขึ้น

## เช็คลิสต์ที่ต้องผ่านทุกครั้งที่แก้หน้าสาธารณะ

- [ ] ป้ายชื่อช่องกรอกเขียนอยู่จริง ไม่ใช่ placeholder อย่างเดียว
- [ ] ปุ่มมีคำ ไม่ใช่ไอคอนเปล่า ๆ
- [ ] กดแล้วมีสัญญาณว่ากำลังทำงาน (`กำลังค้นหา...`)
- [ ] ไม่มีข้อมูลที่ต้องเอาเมาส์ไปชี้จึงจะเห็น (มือถือไม่มี hover)
- [ ] สถานะ "ไม่พบ" บอกวิธีทำต่อ ไม่ใช่บอกแค่ว่าไม่พบ
- [ ] แสดงชื่อโรงเรียนคู่กับชื่อเสมอ (คนชื่อพ้องกันมีจริง)
- [ ] ไอคอนเป็น SVG ไม่ใช่ emoji
- [ ] ตรวจที่ 375 / 768 / 1024 / 1440px ไม่มีแถบเลื่อนแนวนอน

## หมายเหตุเรื่องผลค้นที่ไม่ได้ใช้

`--design-system` คืน style = Exaggerated Minimalism และ typography เป็นคู่ฟอนต์ละติน
(Libre Bodoni / EB Garamond) ทั้งสองอย่างไม่เหมาะกับงานนี้ — ตัวอักษร clamp ขนาดยักษ์
กินพื้นที่บนมือถือ และฟอนต์ละตินไม่มีสระวรรณยุกต์ไทย จึงใช้ผลจาก `--domain` ที่ตรงกว่าแทน
