# หน้าหลังบ้าน (admin) — ส่วนที่ต่างจาก MASTER.md

อ่าน `../MASTER.md` ก่อน ไฟล์นี้เขียนเฉพาะจุดที่ต่าง

## ใช้ธีมเดียวกับหน้าค้นหาทั้งหมด

สี ฟอนต์ กรอบโฟกัส และรูปแบบปุ่ม ใช้ชุดเดียวกับฝั่งผู้ปกครองทุกอย่าง
เพราะเป็นระบบเดียวกัน และคนที่ดูแลระบบคือคนที่ตอบคำถามผู้ปกครอง
ถ้าสองฝั่งหน้าตาคนละแบบ เวลาคุยกันจะอ้างอิงกันไม่ถูกว่าปุ่มไหนคือปุ่มไหน

ที่มาเพิ่มเติม: `--domain product` แถว **Government/Public Service**
→ Accessible & Ethical + Minimalism, professional blue + high contrast
ซึ่งเป็นตระกูลเดียวกับที่ MASTER.md ใช้อยู่แล้ว

## สิ่งที่ต่าง

| เรื่อง | ฝั่งผู้ปกครอง | ฝั่งแอดมิน |
|---|---|---|
| ความหนาแน่น | โปร่ง ตัวใหญ่ | ถี่กว่า ตัวปกติ — เจ้าหน้าที่ทำงานซ้ำ ๆ ต้องเห็นของเยอะในจอเดียว |
| ปุ่มหลัก | สูง 48–56px | สูง 44px |
| ปุ่มรอง | ไม่มี | สูง 40px มีขอบ พื้นขาว |
| หัวเว็บ | โลโก้ + ชื่อระบบ | `AdminShell` — โลโก้ + "ระบบหลังบ้าน" + ลิงก์ไปหน้าค้นหา + ออกจากระบบ |

## token เพิ่มของฝั่งนี้

สีบอก **สถานะของงาน** แยกจากสีรางวัลชัดเจน ถ้าใช้ชุดเดียวกันจะอ่านสับสน
ว่านี่คือรางวัลหรือสถานะ

| token | ใช้กับ |
|---|---|
| `--color-ok-{bg,ink,line}` | เผยแพร่แล้ว / ทำสำเร็จ |
| `--color-warn-{bg,ink,line}` | รอตรวจ / ต้องตามเก็บ / ใกล้หมดอายุ |
| `--color-danger-{bg,ink,line}` | ล้มเหลว / กำลังลบ / โซนอันตราย |

## กฎที่ต้องรักษา

1. **ป้ายสถานะมีที่เดียว** — `StatusBadge.tsx` ห้ามเขียนข้อความหรือสีสถานะซ้ำในหน้าอื่น
   (เคยเหลื่อมกันมาแล้ว หน้าหนึ่งขึ้นภาษาไทย อีกหน้าขึ้น `DELETING` ดิบ ๆ)
2. **ห้ามใช้สีดิบของ Tailwind** (`gray-500`, `red-600`, ...) ในหน้าแอดมิน ใช้ token เท่านั้น
3. **โซนอันตรายต้องพิมพ์ยืนยัน** ไม่ใช้กล่อง confirm ที่กดผ่านได้ในหนึ่งวินาที
4. **ทุกปุ่มมี `cursor-pointer` และ `transition duration-200`** เหมือนฝั่งผู้ปกครอง
5. **หน้า login ต้องเรนเดอร์จากเซิร์ฟเวอร์ได้ทั้งใบ** ห้ามใช้ `useSearchParams`
   เพราะจะลาก Suspense ทั้งหน้า แล้วผู้ใช้เห็นแค่ "กำลังโหลด..." ก่อนฟอร์มโผล่
