# บันทึกการอ่านข้อความจากไฟล์เกียรติบัตร

> **สถานะ: ยังไม่ได้ปรับจูนกับไฟล์จริง**
> โค้ดปัจจุบันใช้วิธีทั่วไปที่ใช้ได้กับเกียรติบัตรส่วนใหญ่ แต่ต้องตรวจกับไฟล์จริงก่อนใช้งานจริง
> เมื่อได้ไฟล์จริงมาแล้ว ให้อัปเดตเอกสารนี้พร้อมกับค่า env ที่ต้องตั้ง

## วิธีหาชื่อแบบปริยาย

`apps/worker/app/tasks/extract.py` เลือก **บรรทัดที่ฟอนต์ใหญ่ที่สุดในหน้า**
โดยข้ามบรรทัดที่เข้าข่ายข้อความประกอบ (`certificate`, `เกียรติบัตร`, `award`, ...)

ใช้ได้เพราะเกียรติบัตรเกือบทุกแบบวางชื่อผู้รับให้เด่นที่สุดในหน้า

## ถ้าวิธีปริยายใช้ไม่ได้

ตั้ง env `NAME_PATTERN` เป็น regex ที่มี capture group เดียว เช่น

```bash
NAME_PATTERN="ขอมอบเกียรติบัตรฉบับนี้ให้ไว้เพื่อแสดงว่า\s*\n\s*(.+)"
```

regex จะถูกใช้กับข้อความทั้งหน้า (`re.IGNORECASE | re.MULTILINE`)

## การตรวจสัญชาติ (เฉพาะ batch รวมประเทศ)

ตั้งต้นที่ `from\s+THAILAND` (ไม่สนตัวพิมพ์เล็กใหญ่)
ถ้าไฟล์จริงเขียนต่างออกไป เช่น `Thailand` อยู่คนละบรรทัดกับ `from`
หรือใช้คำว่า `Nationality: Thai` ให้ตั้ง env `NATIONALITY_PATTERN` ทับ

**หน้าที่ไม่พบข้อความสัญชาติเลย จะถูกถือว่าไม่ใช่คนไทยและถูกข้าม**
ตั้งใจให้เป็นแบบนี้ เพราะปลอดภัยกว่าการเผลอเอาเกียรติบัตรของชาติอื่นเข้าระบบ
ถ้ายอดที่ข้ามสูงผิดปกติ ให้ดูค่า `foreignSkipped` ในหน้าสรุปของ batch แล้วตรวจ regex

## วิธีสำรวจไฟล์จริง

```bash
docker compose exec worker python - <<'PY'
import pymupdf
doc = pymupdf.open("/app/tmp/ไฟล์จริง.pdf")
page = doc[0]
print("=== ข้อความทั้งหน้า ===")
print(page.get_text("text"))
print("=== ขนาดฟอนต์แต่ละบรรทัด ===")
for block in page.get_text("dict")["blocks"]:
    for line in block.get("lines", []):
        text = "".join(s["text"] for s in line["spans"]).strip()
        size = max((s["size"] for s in line["spans"]), default=0)
        if text:
            print(f"{size:6.1f}  {text}")
PY
```

วางไฟล์ไว้ที่ `apps/worker/tmp/` (โฟลเดอร์นี้ถูก gitignore ไว้แล้ว)
**ห้าม commit ไฟล์จริงเข้า git** เพราะเป็นข้อมูลส่วนบุคคล
