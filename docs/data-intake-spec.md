# สเปกการรับและนำเข้าข้อมูลปัจจุบัน

ปรับปรุง 1 ตุลาคม 2569 อ้างอิง schema, API แอดมิน, tasks ของ worker และโปรไฟล์ร่วม คู่มือคนใช้งานอยู่ที่ `admin-guide.md`

## 1 ลำดับงาน

สร้างรอบ → อัป Excel → ตรวจร่างและรายการชน → กดใช้รายชื่อ → อัป ZIP → ตรวจหน้าค้างและไฟล์ขาด → ตรวจยอด → เผยแพร่

หนึ่งรายการสอบ หนึ่งรอบ หนึ่งปี ค.ศ. ใช้หนึ่งรอบนำเข้า มีทั้ง Online และ Onsite อัปเพิ่มได้หลายครั้ง **ไม่รับ ZIP ก่อนมีรายชื่อที่ใช้งาน**

รองรับ HKIMO TIMO BBB HKICO HKISO ทั้ง Heat และ Final จาก `shared/certificate-profiles/` และ registry.py ไม่มีโปรไฟล์กลางสำหรับเดารายการใหม่

## 2 Excel

| คอลัมน์ | บังคับ | ข้อกำหนด |
|---|---|---|
| CANDIDATE NO | ใช่ | ตัวเลขล้วน ตรง Cert No ไม่ซ้ำทั้งไฟล์รวมสองโหมด |
| CANDIDATE NAME | ใช่ | ชื่อยืนยันเลข แนะนำอังกฤษตรงกับใบ |
| EXAM MODE | ใช่ | ONLINE หรือ ONSITE ไม่สน case และช่องว่างหัวท้าย |
| GRADE | ไม่ | ระดับชั้น |
| SCHOOL | ไม่ | โรงเรียน |
| AWARD | ไม่ | คำใบ้เพื่อตามไฟล์ ไม่กำหนดรางวัลของใบ |

ตัวอ่านรองรับ alias หัวคอลัมน์ ตรวจทั้งไฟล์และรายงานแถวผิดทั้งหมด ไม่ผ่านไม่เปลี่ยนรายชื่อเดิม การใช้ร่างต้องแอดมินยืนยัน หากชนคนที่เพิ่มเอง เลือกรวมเป็นคนเดียวพร้อมเลือกค่ารายฟิลด์ หรือเก็บรายการเพิ่มเองไว้ รายการเพิ่มเองที่ไม่ชนยังอยู่

## 3 ZIP

รองรับสองแบบ ห้ามปนใน ZIP เดียว:

```text
แบบรางวัลอย่างเดียว             แบบโหมดแล้วรางวัล
Gold/รวม.pdf                    online/Gold/รวม.pdf
Silver/รวม.pdf                  onsite/Silver/รวม.pdf
Perfect Score/รวม.pdf           online/Perfect Score/รวม.pdf
```

มีโฟลเดอร์ครอบนอกได้หนึ่งชั้น HKISO Heat มีระดับชั้นใต้รางวัลเพิ่มได้หนึ่งชั้น รางวัลจากโฟลเดอร์เท่านั้น ชื่อ PDF ไม่กำหนดรางวัล โฟลเดอร์ผิดทำให้ตรวจ ZIP ไม่ผ่านทั้งไฟล์ ไม่เดาหรือข้าม

รางวัลและ alias จาก manifest รายการและรอบ เช่น BBB Gold เป็น 1st Prize และ HKICO Gold รองรับ Participation เฉพาะ Heat มี PRIMARY / SUPPLEMENTAL ใน manifest

รับ PDF ไม่รับ JPG/PNG ไม่มี OCR สำหรับภาพไม่มี text layer ต้องเตรียม PDF ที่โปรไฟล์อ่านได้

## 4 อ่านและจับคู่

- ดาวน์โหลด ZIP ลงดิสก์ อ่าน PDF ทีละไฟล์ ไม่โหลดทั้งหมดเข้าหน่วยความจำ
- โปรไฟล์ตามรายการและรอบอ่านชื่อ เลข ระดับชั้น โรงเรียนหรือประเทศ รอบ ปี และข้อความรางวัลตรวจทาน
- Heat รับทุกหน้า from อาจเป็นโรงเรียน Final รับไทย ประเทศอื่น SKIPPED_FOREIGN ไม่มีหลักฐานประเทศ NATIONALITY_UNVERIFIED
- **รางวัลจากชื่อโฟลเดอร์เท่านั้น** Perfect Score อาจไม่มีข้อความรางวัลบนใบ Excel อาจมีแค่รางวัลสูงสุด
- เทียบเลขกับ RosterEntry ในรอบและตรวจชื่อ เลขตรงแต่ชื่อผิด NAME_MISMATCH
- ZIP รางวัลอย่างเดียวใช้โหมดจาก roster พร้อม modeSource=ROSTER เมื่อเปลี่ยน roster คำนวณใหม่ ไม่ถือว่ามีหลักฐานโหมดจากโฟลเดอร์
- ZIP แยกโหมดตรวจเทียบ roster ไม่ตรง MODE_MISMATCH ข้อความ ONLINE/ONSITE บนใบเมื่ออ่านได้ก็ตรวจเทียบ
- ชื่อซ้ำหรือระบุตัวไม่ได้ให้แอดมินตัดสิน ห้ามเดาสร้างตัวคนใหม่ ตัวคนข้ามปีต้องมีหลักฐานยืนยัน
- โรงเรียนบนใบไม่ตรง roster เป็นคำเตือน ไม่เขียนทับจากใบเอง

## 5 นำเข้าซ้ำและความล้มเหลว

ตรวจ fingerprint และคีย์ผู้เข้าสอบกับรางวัล ข้ามหน้าเดิม/ใบที่มีแล้ว หน้าใหม่จัดโหมดถูกแทนหน้าปัญหาเดิมได้ ดูผลในประวัติการอัป

SPLIT ที่ล้มเหลวย้อนหน้าที่สร้างและไฟล์ของงาน คืนหน้าที่ถูกแทน ROSTER_ACTIVATE ทำใน transaction ล้มเหลวใช้รายชื่อเดิมต่อ คิวป้องกันงานในรอบเดียวกันทำพร้อมกัน ดู jobs กับ runner.py ห้ามแก้คิวโดยเดาว่างานค้าง

## 6 PDF รายคนและแก้ข้อมูล

PDF รายคนต้องเลือกรางวัลและตรวจเลขกับชื่อ รวมเล่มคัดหน้าของคนที่ระบุ ระบุหน้าไม่ได้ให้ขอไฟล์หรือแยกเอง ใช้ pipeline ตรวจเดียวกับ ZIP

แก้ชื่อ เลข โหมด รางวัล ไฟล์และตัวคนมี audit และ version กันสองแท็บเขียนทับ แก้ไม่ได้ขณะเผยแพร่หรือมีงานล็อกรอบ ทิ้งหน้าคงหลักฐาน ไม่เหมือนลบรอบจริง

## 7 เผยแพร่และดูแลไฟล์

เผยแพร่คนที่พร้อม ค้างคนมีปัญหาและคนไม่มีใบหลัก เฉพาะใบเสริมต้องยืนยันชุดปัจจุบันรายคน นโยบายรอบแสดงทุกใบหรือเฉพาะหลัก ซ่อนไม่ลบ

RETENTION_MONTHS ปริยาย 24 ตั้งหมดอายุเมื่อเผยแพร่ครั้งแรก ลบจริงเมื่อ RETENTION_ENABLED=true ต่ออายุผ่านแอดมิน ZIP ล้างเมื่อครบเงื่อนไขและ SOURCE_ZIP_KEEP_DAYS ไม่ใช่ backup

ลบรอบผ่านหน้าแอดมิน/API ที่คิว DELETE_BATCH จัดการไฟล์และความสัมพันธ์ ห้าม DELETE FROM batches เอง
