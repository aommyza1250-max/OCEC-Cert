# คู่มือแอดมิน: การนำเข้าและแก้ไขข้อมูลเกียรติบัตร

คู่มือนี้สำหรับ **คนที่นำเข้าข้อมูลจริง** ไม่ใช่คนเขียนโค้ด
บอกว่าเจอสถานการณ์ไหนให้กดปุ่มไหน และข้อความที่ขึ้นหมายความว่าอะไร

> รายละเอียดเชิงเทคนิคอยู่ใน [data-intake-spec.md](data-intake-spec.md)
> วิธีแก้ตอนระบบมีปัญหาอยู่ใน [runbook.md](runbook.md)

---

## หลักการที่ควรรู้ก่อน

1. **ระบบไม่เดา ถ้าไม่มั่นใจจะส่งให้คุณตัดสิน**
   จับคู่ผิดคนหมายความว่าผู้ปกครองจะดาวน์โหลดเกียรติบัตรของเด็กคนอื่น ซึ่งแก้ย้อนหลังไม่ได้
   ทุกรายการที่ระบบค้างไว้ในหัวข้อ "หน้าที่ต้องตัดสิน" คือเรื่องที่ระบบตัดสินแทนคุณไม่ได้
2. **ต้องมีรายชื่อก่อนเสมอ** เพราะรายชื่อบอกว่ารอบนี้มีใครบ้าง ทั้ง online และ onsite
   ถ้ายังไม่มีรายชื่อ ระบบจะไม่ให้อัปเกียรติบัตร
3. **อัปเพิ่มได้เรื่อย ๆ และไม่ลบของเดิม**
   ใบที่ระบบรับไปแล้วจะไม่ถูกแตะ ถ้าอัปไฟล์ซ้ำ ระบบจะข้ามให้เอง
4. **ระหว่างเผยแพร่ แก้อะไรไม่ได้เลย** ต้องกด "ยกเลิกการเผยแพร่" ก่อนทุกครั้ง
5. **ทุกการแก้ไขถูกบันทึกไว้** ดูย้อนหลังได้ที่หัวข้อ "การแก้ไขล่าสุด"
   ระบบบันทึกว่าแก้อะไร จากค่าอะไรเป็นค่าอะไร เมื่อไร และจากการล็อกอินครั้งไหน

online/onsite เป็นข้อมูลที่แอดมินเห็นคนเดียว **ผู้ปกครองไม่เห็นในหน้าค้นหา**

---

## 1. ภาพรวมขั้นตอน

```
สร้างรอบนำเข้า → อัปรายชื่อ → กด "ใช้รายชื่อชุดนี้" → อัป ZIP เกียรติบัตร (กี่ครั้งก็ได้)
            → จัดการ "หน้าที่ต้องตัดสิน" และ "ผู้เข้าสอบที่ยังไม่มีเกียรติบัตร" → เผยแพร่
```

### 1.1 สร้างรอบนำเข้า

เลือกรายการสอบ + รอบ (Heat/Final) + ปี ค.ศ.

- **1 รายการสอบ + 1 รอบ + 1 ปี = 1 รอบนำเข้าเท่านั้น** ในรอบเดียวมีทั้ง online และ onsite
  ถ้าสร้างซ้ำ ระบบจะเตือนและมีปุ่มพาไปยังรอบเดิม
- รายการสอบที่ระบบยังอ่านเกียรติบัตรไม่เป็น จะขึ้นในตารางว่า **"ยังไม่รองรับ"** และสร้างรอบนำเข้าไม่ได้
  ตอนนี้รองรับ HKIMO, TIMO, BBB, HKICO และ HKISO ทั้งรอบ Heat และ Final
  ถ้าต้องการเพิ่มรายการใหม่ ต้องให้คนเขียนโค้ดเพิ่มโปรไฟล์ให้ (ดู [certificate-profiles.md](certificate-profiles.md))
- หน้ารอบนำเข้าจะแสดงชื่อโปรไฟล์ที่ใช้ เช่น `HKIMO_FINAL` ไว้ใช้บอกผู้ดูแลระบบตอนมีปัญหา

### 1.2 อัปรายชื่อ (Excel)

ใช้ **Excel ไฟล์เดียวที่มีทั้งผู้เข้าสอบ online และ onsite**

| หัวคอลัมน์ | บังคับ | ใช้ทำอะไร |
|---|---|---|
| `CANDIDATE NO` | ✅ | **สำคัญที่สุด** ต้องเป็นตัวเลขล้วน และไม่ซ้ำกันทั้งไฟล์ (รวม online และ onsite) ตรงกับ `Cert No` บนเกียรติบัตร |
| `CANDIDATE NAME` | ✅ | ชื่อภาษาอังกฤษ ใช้ยืนยันว่าเลขไม่ได้ชนกันโดยบังเอิญ (จะใช้ชื่อภาษาไทย หรือแยกชื่อ/นามสกุลก็ได้) |
| `EXAM MODE` | ✅ | `ONLINE` หรือ `ONSITE` เท่านั้น (ตัวพิมพ์เล็ก-ใหญ่ และช่องว่างหัวท้ายไม่มีผล) |
| `GRADE` | | ระดับชั้น |
| `SCHOOL` | | โรงเรียน |
| `AWARD` | | ใช้เป็นคำใบ้ตอนตามไฟล์ที่ขาด **ไม่ใช่** ที่มาของรางวัลบนเกียรติบัตร |

หัวคอลัมน์เขียนแบบอื่นก็ได้ เช่น `Mode`, `รูปแบบการสอบ`, `เลขผู้เข้าสอบ`, `ชื่อ-นามสกุล`

**ระบบตรวจทั้งไฟล์ก่อน** ถ้ามีแถวไหนผิด จะไม่รับทั้งไฟล์ แล้วแสดงรายการแถวที่ผิด **ทั้งหมดในครั้งเดียว**
(เช่น "แถว 14: รูปแบบการสอบ 'Onlin' ไม่ถูกต้อง") ให้แก้ Excel ตามรายการแล้วอัปใหม่
ระหว่างนี้รายชื่อชุดที่ใช้อยู่จะไม่ถูกแตะ

### 1.3 กด "ใช้รายชื่อชุดนี้"

ถ้าไฟล์ผ่านการตรวจ ระบบจะแสดงร่างพร้อมยอด **ทั้งหมด / Online / Onsite** ให้เทียบกับที่ต้นทางแจ้งมา
ถ้ายอดตรงก็กด **"ใช้รายชื่อชุดนี้"** ถ้าไม่ตรง ให้กดทิ้งร่างแล้วอัปไฟล์ที่ถูกต้อง

ระบบไม่เปลี่ยนรายชื่อเองโดยอัตโนมัติ ต้องให้คุณกดยืนยันก่อนเสมอ

**ถ้าร่างชนกับผู้เข้าสอบที่คุณเพิ่มเอง** (เลขเดียวกัน หรือชื่อเดียวกันแต่เลขต่างกัน)
ระบบจะให้ตัดสินทีละรายการก่อนกดใช้:

| ตัวเลือก | ผล |
|---|---|
| **คนเดียวกัน — รวมเป็นรายการเดียว** | เลือกได้ทีละช่องว่าจะใช้ค่าจาก Excel หรือค่าที่เพิ่มเอง หลังรวมแล้วจะนับเป็นรายการจาก Excel |
| **เก็บรายการที่เพิ่มเองไว้** | ไม่ใช้แถวนั้นใน Excel |

ผู้เข้าสอบที่เพิ่มเองซึ่งไม่ชนกับใคร **อยู่ต่อทุกครั้งที่อัป Excel ชุดใหม่**

### 1.4 อัป ZIP เกียรติบัตร

อัปได้ **2 รูปแบบ** โดยไม่ต้องเลือกชนิดไฟล์เอง ระบบดูจากโครงโฟลเดอร์:

1. **แยกตามรางวัลอย่างเดียว** เช่น `Gold/ใบรวม.pdf`, `Silver/ใบรวม.pdf` — PDF เดียวมีทั้ง Online และ Onsite ได้ ระบบอ่าน `Cert No` บนแต่ละหน้า หาผู้เข้าสอบในรายชื่อ ตรวจชื่อ แล้วใช้โหมดจากรายชื่อ
2. **แยกตามโหมดแล้วตามรางวัล** ดังตัวอย่างด้านล่าง — โหมดมาจากโฟลเดอร์ และระบบตรวจเทียบกับรายชื่อ

ห้ามปนสองรูปแบบใน ZIP เดียวกัน ถ้าต้องอัปทั้งสองแบบ ให้อัปคนละ ZIP

```
HKIMO_Final_2026.zip
 ├── online/
 │    ├── Gold/           *.pdf
 │    ├── Silver/         *.pdf
 │    └── Perfect Score/  *.pdf
 └── onsite/
      ├── Gold/           *.pdf
      └── Merit/          *.pdf
```

- ZIP หนึ่งไฟล์จะมีทั้ง `online/` และ `onsite/` หรือมีแค่อันเดียวก็ได้
- จะมีโฟลเดอร์ครอบไว้ข้างนอกอีก 1 ชั้นก็ได้ (เช่น `HKIMO/online/Gold/*.pdf`) ปกติจะได้ชั้นนี้มาเองตอนบีบอัดทั้งโฟลเดอร์
- **HKISO รอบ Heat** มีโฟลเดอร์ระดับชั้นใต้โฟลเดอร์รางวัลได้อีก 1 ชั้น เช่น `online/Gold/P3/*.pdf`
- ชื่อไฟล์ PDF ข้างในจะตั้งว่าอะไรก็ได้
- **รางวัลอ่านจากชื่อโฟลเดอร์เท่านั้น** เพราะเกียรติบัตร Perfect Score ไม่มีข้อความรางวัลพิมพ์ไว้
- สำหรับ ZIP แยกตามรางวัล โหมดที่แสดงเป็นค่าจากรายชื่อ ไม่ใช่หลักฐานที่อ่านได้จากโฟลเดอร์ หากเลขบนใบไม่มีในรายชื่อ อ่านเลขหรือชื่อไม่ได้ หรือชื่อไม่ตรง ระบบค้างหน้าไว้ให้ตรวจ ไม่จับคู่เอง
- ถ้ามี `ONLINE` หรือ `ONSITE` เป็นบรรทัดแยกบนใบ (หรือ `Exam Mode: ONLINE/ONSITE`) ระบบตรวจเทียบกับรายชื่อ ถ้าไม่ตรงจะเป็นปัญหา `MODE_MISMATCH` ให้ตัดสิน
- โรงเรียนบนใบที่ไม่ตรงกับรายชื่อเป็นคำเตือนให้ตรวจทาน เพราะชื่อโรงเรียนอาจสะกดต่างกัน

**ชื่อโฟลเดอร์รางวัลที่รับได้** ไม่สนตัวพิมพ์เล็ก-ใหญ่ และจะใช้ `_` `-` หรือช่องว่างก็ได้
หน้าอัปโหลดแสดงรายชื่อโฟลเดอร์ที่รอบนั้นรับได้ไว้เสมอ

| รายการสอบ | รางวัลหลัก | รางวัลเสริม |
|---|---|---|
| HKIMO / TIMO / HKISO | Gold, Silver, Bronze, Merit, Participation (Heat เท่านั้น) | Perfect Score, Special Award |
| HKICO | เหมือนข้างบน และรับชื่อแบบ `HKICO Gold` ด้วย | เหมือนข้างบน |
| BBB | 1st Prize, 2nd Prize, 3rd Prize (รับโฟลเดอร์ `Gold`/`Silver`/`Bronze` ด้วย), Merit, Participation (Heat เท่านั้น) | Perfect Score, Special Award |

> BBB ใช้ชื่อรางวัลจริงของ BBB คือ **1st Prize** ไม่ใช่ Gold
> ถ้าต้นทางตั้งชื่อโฟลเดอร์ว่า `Gold` ระบบจะรับได้ แต่บนเว็บจะแสดงเป็น 1st Prize ตามที่พิมพ์บนเกียรติบัตร

**ระบบตรวจโครงสร้าง ZIP ทั้งไฟล์ก่อนเริ่มตัดหน้า** ถ้าเจอปัญหาจะไม่รับทั้งไฟล์ และข้อมูลเดิมจะไม่ถูกแตะ
ปัญหาทั้งหมดจะแสดงพร้อมกันในครั้งเดียว (ดูหัวข้อ 6)

**อัปซ้ำได้ไม่จำกัด** ระบบจะ:
- ข้ามใบที่ผู้เข้าสอบคนนั้นมีรางวัลเดียวกันอยู่แล้ว (ดูจาก **เลขผู้เข้าสอบคู่กับรางวัล**)
- ข้ามหน้าเดิมที่เคยอัปแล้ว ไม่สร้างรายการให้ตัดสินซ้ำ
- ถ้าเคยอัปไฟล์ผิดโฟลเดอร์ online/onsite ไว้ แล้วอัปไฟล์ที่จัดถูกเข้ามา **ไฟล์ใหม่จะมาแทนไฟล์เดิม** และรายการที่ต้องตัดสินของไฟล์เดิมจะหายไปเอง

ดูผลของการอัปแต่ละครั้งได้ที่ **"ประวัติการอัป"** เช่น หน้าที่อ่าน, หน้าใหม่, ข้าม (มีใบแล้ว), แทนหน้าที่ติดปัญหา

ชื่อไฟล์ที่ระบบตั้งให้คือ `{ชื่อ}_{นามสกุล}_{รายการสอบ}_{รอบ}_{รางวัล}_{ปี}.pdf`
เช่น `SOMCHAI_JAIDEE_HKIMO_FINAL_GOLD_2026.pdf`

## 2. จัดการสิ่งที่ระบบค้างไว้

หน้ารอบนำเข้ามี 2 รายการที่ต้องดู: **"หน้าที่ต้องตัดสิน"** กับ **"ผู้เข้าสอบที่ยังไม่มีเกียรติบัตร"**
ถ้ายังไม่จัดการ ผู้เข้าสอบคนนั้นจะถูกค้างไว้ตอนเผยแพร่ แต่ไม่ขัดขวางคนอื่น

### 2.1 หน้าที่ต้องตัดสิน

ทุกรายการจะแสดงรูปตัวอย่าง ชื่อ เลข และระดับชั้นที่อ่านได้จากหน้า เทียบกับข้อมูลในรายชื่อ
และบอกว่ามาจาก ZIP ไฟล์ไหน โฟลเดอร์ไหน

| ขึ้นว่า | หมายความว่า | ปุ่มที่มีให้ |
|---|---|---|
| **online/onsite ไม่ตรง** | เลขและชื่อตรงกับรายชื่อ แต่ไฟล์อยู่ในโฟลเดอร์ online/onsite ที่ไม่ตรงกับรายชื่อ | **ใช้รูปแบบตามรายชื่อ** (ยืนยันว่ารายชื่อถูก) · **ทิ้งและรอไฟล์ใหม่** · หรืออัป ZIP ที่ย้ายไฟล์ไปโฟลเดอร์ที่ถูก หน้าเดิมจะถูกแทนเอง |
| **ชื่อไม่ตรง** | เลขตรงกับรายชื่อ แต่ชื่อบนหน้าไม่ตรง | **คนเดียวกัน — จับคู่ด้วยมือ** · **แก้ชื่อในรายชื่อ** (ถ้ารายชื่อสะกดผิด) · **ทิ้งหน้านี้** (ถ้าไฟล์ผิดคน) |
| **ยังไม่มีคู่** | ไม่มีใครในรายชื่อที่ตรงกับหน้านี้ | กรอกเลขแล้วกด **ผูกกับเลขนี้** · **เพิ่มเป็นผู้เข้าสอบที่ตกหล่น** (ข้อ 3.1) แล้วระบบจะจับคู่ให้เอง · **ทิ้งหน้านี้** |
| **ระบุตัวไม่ได้** | อ่านเลขบนหน้าไม่ได้ และในรายชื่อมีคนชื่อเดียวกันหลายคน | กด **เป็นของ (เลข · ชื่อ)** ของคนที่ถูก |
| **ใบซ้ำ รอตัดสิน** | คนนี้มีใบรางวัลเดียวกันที่รับไปแล้ว แต่ไฟล์ไม่เหมือนกัน | **ใช้หน้านี้แทนใบเดิม** · **ใบซ้ำ — ทิ้งหน้านี้** |
| **รอยืนยันสัญชาติ** | รอบ Final แต่หน้านี้ไม่มีข้อความยืนยันว่าเป็นคนไทย | **เป็นผู้เข้าสอบไทย** · **ต่างชาติ — ไม่นำเข้า** |
| **รอบ/ปีไม่ตรง** | รอบหรือปีที่พิมพ์บนหน้าไม่ตรงกับรอบนำเข้านี้ | **เป็นของรอบนี้จริง — รับไว้** · **ทิ้งหน้านี้** |

ถ้าใบซ้ำเกิดจากต้นทางวางไฟล์ผิดโฟลเดอร์รางวัล (เช่น ใบ Silver อยู่ในโฟลเดอร์ Gold) ให้กด **"เปลี่ยนรางวัล"** ในรายการนั้น
ต้องกดยืนยันก่อน และเลือกได้เฉพาะรางวัลของรายการและรอบนี้ที่ผู้เข้าสอบคนนั้นยังไม่มี
ระบบยังเก็บรางวัลตามโฟลเดอร์เดิมไว้เป็นหลักฐานเสมอ (ใบที่รับไปแล้วเปลี่ยนรางวัลได้จากหน้าผู้เข้าสอบ ข้อ 3.4)

หน้าที่ทิ้งไปแล้วไม่ได้ถูกลบ ถ้าหน้านั้นผูกกับผู้เข้าสอบ หรือมีเลขผู้เข้าสอบที่อ่านได้ จะคืนได้จากหน้าของผู้เข้าสอบคนนั้น

### 2.2 ผู้เข้าสอบที่ยังไม่มีเกียรติบัตร

แสดงทุกคนในรายชื่อที่ยังไม่มีเกียรติบัตรเลย แยกยอด online/onsite ให้
และแสดงคนที่มีแค่ใบรางวัลเสริม (เช่น Perfect Score) แต่ยังไม่มีใบรางวัลหลัก

- **ใช้รายการนี้แจ้งต้นทางได้เลย** มีทั้งเลขผู้เข้าสอบ ชื่อ และรางวัลตามที่ Excel ระบุ
- **ได้ไฟล์มาไม่กี่คน:** เลือกรางวัลของไฟล์ แล้วกด **"เลือกไฟล์ PDF ที่ได้มา"** ในแถวของคนนั้น
  - ต้องเลือกรางวัลเองทุกครั้ง ระบบไม่เดาจากข้อความบนหน้าหรือจาก Excel
  - ไฟล์รวมเล่มหลายหน้าก็ได้ ระบบจะคัดเฉพาะหน้าของคนนั้น (เลขและชื่อต้องตรงกัน)
  - ถ้าหยิบไฟล์ผิดคน ระบบจะไม่รับ และบอกว่าไฟล์นั้นเป็นของใคร โดยไม่แตะข้อมูลเดิม
- **ได้ไฟล์มาหลายคน:** อัป ZIP ตามโครงเดิมได้เลย ระบบจะเติมเฉพาะใบที่ยังไม่มี

## 3. ค้นหาและแก้ไขผู้เข้าสอบ

กด **"ค้นหาและแก้ไขผู้เข้าสอบ"** ที่หน้ารอบนำเข้า
ค้นได้ทั้งชื่อและเลขผู้เข้าสอบ และกรองได้ตามรูปแบบการสอบ รางวัล ปัญหา ที่มา (Excel/เพิ่มเอง) และมีไฟล์หรือยัง

### 3.1 เพิ่มผู้เข้าสอบที่ตกหล่นจาก Excel

กรอกเลขผู้เข้าสอบ (ห้ามซ้ำกับใครในรอบนี้ ทั้ง online และ onsite) ชื่อ และรูปแบบการสอบ
จะกรอกโรงเรียน ระดับชั้น และรางวัลที่คาดไว้ด้วยก็ได้

ระบบจะลองจับคู่กับหน้าที่ค้างอยู่ให้ทันที ถ้ายังไม่มีหน้าของคนนี้ ชื่อจะไปขึ้นใน "ผู้เข้าสอบที่ยังไม่มีเกียรติบัตร"

### 3.2 แก้ข้อมูลการสอบ

แก้ชื่อ เลขผู้เข้าสอบ รูปแบบการสอบ โรงเรียน และระดับชั้นได้ พอกดบันทึก ระบบจะจับคู่ใหม่ให้เอง

- ถ้าแก้พร้อมกันจากสองแท็บ แท็บที่บันทึกทีหลังจะถูกปฏิเสธ และขึ้นให้รีเฟรชก่อน ระบบจะไม่เขียนทับกันเอง
- ลบได้เฉพาะคนที่เพิ่มเอง ส่วนคนที่มาจาก Excel ต้องแก้ใน Excel แล้วอัปใหม่

### 3.3 ตัวคน (ข้ามรายการสอบและข้ามปี)

ผู้เข้าสอบในรอบนี้ผูกกับ "ตัวคน" ที่ผู้ปกครองค้นเจอ ซึ่งอาจมีเกียรติบัตรจากรายการหรือปีอื่นด้วย

- ถ้าระบบเจอคนชื่อเดียวกันหลายคนแล้วแยกไม่ออก จะให้คุณเลือกคนเดิม หรือกด **"คนใหม่ ไม่ใช่คนใดข้างบน"**
- ถ้าเจอว่าระบบรวมคนสองคนเป็นคนเดียวกัน ให้แยกเป็นคนใหม่ อย่าแก้ชื่อตัวคนแทน
- หน้าผู้เข้าสอบจะบอกว่าตัวคนนี้มีเกียรติบัตรจากรายการอื่นอีกกี่ใบ ถ้าผูกผิดคน ให้กด **"ผูกผิดคน — แยกเป็นคนใหม่"**
  ใบของรายการอื่นจะยังอยู่กับคนเดิมตามเดิม

### 3.4 เกียรติบัตรของคนนี้

| ทำอะไรได้ | หมายเหตุ |
|---|---|
| **เปลี่ยนไฟล์ PDF** | ไฟล์ใหม่ต้องเป็นของคนนี้ (เลขและชื่อตรงกัน) ใบเดิมจะเก็บไว้เป็นหลักฐาน |
| **เพิ่มเกียรติบัตร** | ต้องเลือกรางวัลเอง และคนเดียวกันมีรางวัลเดียวกันซ้ำสองใบไม่ได้ |
| **เปลี่ยนรางวัล** | ต้องยืนยัน รางวัลตามโฟลเดอร์เดิมยังเก็บไว้ |
| **ทิ้ง / คืน** | ใบที่ทิ้งจะไม่ถูกเผยแพร่ แต่ยังอยู่ในระบบ |

### 3.5 อัปไฟล์ผิดทั้งไฟล์

ถ้าอัป ZIP ผิดทั้งไฟล์ (เช่น ผิดรายการหรือผิดปี) ให้ไปที่ **"ประวัติการอัป"** แล้วกด **"ทิ้งทุกหน้า"** ของไฟล์นั้น
ต้องพิมพ์ชื่อไฟล์เพื่อยืนยัน ระบบจะทิ้งเฉพาะหน้าที่มาจากไฟล์นั้น ส่วนการตัดสินและการแก้ไขอื่นยังอยู่ครบ
หน้าที่ถูกทิ้งยังเก็บไว้เป็นหลักฐาน และคืนทีละหน้าได้จากหน้าของผู้เข้าสอบคนนั้น (เฉพาะหน้าที่ผูกกับผู้เข้าสอบหรือมีเลขที่อ่านได้)

> ถ้าไฟล์ที่ทิ้งเคยมาแทนหน้าเก่าที่ติดปัญหา (เช่น online/onsite ไม่ตรง) หน้าเก่านั้นจะ **ไม่** กลับมาเอง
> ผู้เข้าสอบคนนั้นจะถูกค้างไว้ในฐานะ "ยังไม่มีไฟล์เกียรติบัตร" ให้อัปไฟล์ที่ถูกต้องเข้ามาใหม่

## 4. การเผยแพร่

### เผยแพร่ทีละคน ไม่ต้องรอให้ครบทั้งรอบ

ก่อนกดเผยแพร่ ระบบจะแสดงว่า **จะเผยแพร่กี่คน กี่ใบ** และ **จะค้างไว้กี่คนเพราะอะไร** โดยแยกยอด online/onsite
คนที่ข้อมูลครบจะเผยแพร่ก่อน ส่วนคนที่ยังมีปัญหาจะค้างไว้ ผู้ปกครองจะยังค้นหาคนที่ค้างไว้ไม่เจอ

| เหตุที่ค้างไว้ | แก้โดย |
|---|---|
| ยังไม่มีไฟล์เกียรติบัตร | อัปไฟล์ (ข้อ 2.2) |
| มีแต่ใบรางวัลเสริม ใบรางวัลหลักยังไม่มา | ขอใบรางวัลหลักจากต้นทาง (รางวัลเสริมให้คู่กับรางวัลหลักเสมอ) |
| ชื่อไม่ตรง / online/onsite ไม่ตรง / ระบุตัวไม่ได้ / ใบซ้ำ / รอยืนยันสัญชาติ / รอบ/ปีไม่ตรง | ตัดสินใน "หน้าที่ต้องตัดสิน" (ข้อ 2.1) |

แก้ครบแล้วให้กด **ยกเลิกการเผยแพร่ → แก้ → เผยแพร่อีกครั้ง**
การเผยแพร่แต่ละครั้งจะเผยแพร่ทุกใบที่พร้อม ณ ตอนนั้น และค้างคนที่ยังมีปัญหาไว้เหมือนเดิม

### ⚠️ ยกเลิกการเผยแพร่ = ทั้งรอบหายจากหน้าค้นหาชั่วคราว

ระหว่างนั้นผู้ปกครองจะค้นหาใครในรอบนี้ไม่เจอเลย จนกว่าคุณจะกดเผยแพร่อีกครั้ง
เพราะฉะนั้นควรเตรียมไฟล์ที่จะแก้ให้พร้อมก่อน แล้วค่อยยกเลิก แก้ และเผยแพร่ในรอบเดียว

### ต้องเลือกก่อนเผยแพร่: ฮ่องกงส่งฉบับจริงมาแบบไหน

ถ้ารอบนี้มีคนที่ได้ทั้งรางวัลหลักและรางวัลเสริม (เช่น Gold + Perfect Score) ระบบจะให้เลือกก่อน

| ตัวเลือก | ผล |
|---|---|
| ทุกใบ | ผู้ปกครองเห็นทั้งใบรางวัลหลักและใบรางวัลเสริม |
| เฉพาะใบรางวัลหลัก | ใบรางวัลเสริมของคนที่มีใบหลักด้วยจะถูกซ่อน (ไม่ได้ลบ) |

### รอบที่นำเข้าจากระบบเดิม

รอบที่สร้างก่อนเปลี่ยนมาใช้ขั้นตอนนี้จะขึ้นว่า **"รอบนี้มาจากระบบเดิม"**
รอบแบบนี้ยังเผยแพร่ต่อได้ตามเดิม แต่อัปไฟล์หรือแก้ไขไม่ได้
ถ้ากดยกเลิกการเผยแพร่ จะเผยแพร่กลับไม่ได้ ต้องลบแล้วนำเข้าใหม่ตามขั้นตอนนี้ (ดู [runbook.md](runbook.md))

## 5. อายุการเก็บ การลบ และไฟล์ต้นฉบับ

### อายุการเก็บ 2 ปี

เกียรติบัตรถูกเก็บไว้ **2 ปีนับจากวันเผยแพร่** หลังจากนั้นระบบจะลบไฟล์ออกจากคลาวด์
ผู้ปกครองจะค้นไม่เจอ แต่ข้อมูลว่าใครได้รางวัลอะไรยังอยู่ในระบบ

- หน้ารอบนำเข้าบอกไว้ตั้งแต่แรกว่า "เกียรติบัตร N ใบของรอบนี้จะถูกลบไฟล์วันที่ ..."
- ถ้ามีคนขอให้เก็บต่อ กด **"ต่ออายุอีก 1 ปี"** ที่รอบนั้นได้
- หน้ารวมจะเตือนล่วงหน้า 30 วัน พร้อมปุ่ม **"ลองดูว่าจะลบอะไรบ้าง"** ที่ไม่ลบจริง
- หน้าค้นหาของผู้ปกครองมีข้อความแจ้งนโยบายนี้อยู่ท้ายรายการของแต่ละคน

การลบจริงถูก**ปิดไว้เป็นค่าตั้งต้น** เปิดโดยตั้ง `RETENTION_ENABLED=true` ที่ service `worker`

### ลบรอบการนำเข้าทั้งรอบ

อยู่ท้ายหน้ารอบนำเข้า ในกรอบแดง **"โซนอันตราย"**

ใช้เมื่อต้องการให้รอบนั้นหายไปทั้งหมดจริง ๆ เช่นสร้างผิดปี ผิดรอบ หรืออยากนำเข้าใหม่ทั้งชุด
**ถ้าแค่อัป ZIP ผิดไฟล์ ใช้ "ทิ้งทุกหน้า" ในประวัติการอัปก็พอ** (ข้อ 3.5) ไม่ต้องลบทั้งรอบ

ก่อนลบจะบอกก่อนว่าจะหายไปแค่ไหน แล้ว**ต้องพิมพ์ชื่อรอบยืนยัน** เช่น `HKIMO FINAL 2026`
ถ้ารอบนั้นเผยแพร่อยู่ ต้องติ๊กเพิ่มอีกช่องว่าเข้าใจว่าผู้ปกครองจะค้นไม่เจอทันที

| สิ่งที่หายไป | สิ่งที่ไม่หาย |
|---|---|
| เกียรติบัตร รูปตัวอย่าง รายชื่อ และไฟล์ต้นฉบับของรอบนั้นทั้งหมด | รายการสอบและรอบการสอบ (สร้างรอบนำเข้าใหม่ได้เลย) |
| ข้อมูลการจับคู่และการตัดสินของรอบนั้น | ผู้เข้าสอบที่ยังมีเกียรติบัตรจากรอบอื่น |

บันทึกการแก้ไขของรอบนั้นยังเก็บไว้ ดูย้อนหลังได้ว่าเคยแก้อะไร

**กู้คืนไม่ได้** ถ้าต้องการข้อมูลกลับมาต้องนำเข้าใหม่จากไฟล์ต้นฉบับในเครื่องตัวเอง

### ไฟล์ต้นฉบับ (ZIP) หายไปเอง — ปกติ

หลังเผยแพร่ ทุกคนในรายชื่อมีเกียรติบัตรครบ และไม่มีหน้าค้างให้ตัดสินแล้ว ระบบจะ**ลบไฟล์ ZIP ที่อัปเข้ามาทิ้งอัตโนมัติ**
เพราะไฟล์นั้นใหญ่มาก (หลายร้อย MB) และไม่มีอะไรในระบบเรียกใช้อีกแล้ว
เกียรติบัตร รูปตัวอย่าง และไฟล์รายชื่อ (Excel) ยังอยู่ครบเหมือนเดิม

ดูสถานะได้ที่หัวข้อ **"ไฟล์ต้นฉบับ"** ท้ายหน้ารอบนำเข้า ถ้ายังไม่เคลียร์จะบอกว่าติดเงื่อนไขข้อไหน

ถ้าต้องตัดหน้าใหม่จากต้นฉบับหลังไฟล์ถูกลบไปแล้ว ให้อัป ZIP ขึ้นมาใหม่จากเครื่องตัวเอง

## 6. ข้อความที่อาจเจอ

### ตอนอัปรายชื่อ

| ข้อความ | ทำอะไรต่อ |
|---|---|
| ไม่มีคอลัมน์ EXAM MODE (หรือ CANDIDATE NO / CANDIDATE NAME) | เพิ่มคอลัมน์นั้นใน Excel แล้วอัปใหม่ |
| แถว N: ไม่ได้ระบุรูปแบบการสอบ / รูปแบบการสอบ '...' ไม่ถูกต้อง | ใส่ `ONLINE` หรือ `ONSITE` ในแถวนั้น |
| แถว N: เลขผู้เข้าสอบ '...' ต้องเป็นตัวเลขล้วน | แก้เลขให้ตรงกับ `Cert No` บนเกียรติบัตร |
| เลขผู้เข้าสอบซ้ำ ... | เลขเดียวกันจะอยู่ทั้งใน online และ onsite ไม่ได้ ให้ต้นทางยืนยันว่าคนนั้นสอบแบบไหน |

### ตอนอัป ZIP

ถ้าข้อความขึ้นต้นว่า **"โครงสร้างไฟล์ ZIP ไม่ถูกต้อง จึงยังไม่นำเข้าอะไรเลย"** แปลว่าข้อมูลเดิมยังไม่ถูกแตะเลย

| ปัญหาที่ระบบบอก | ทำอะไรต่อ |
|---|---|
| ไฟล์ PDF ที่ไม่ได้อยู่ในโฟลเดอร์ online หรือ onsite | ย้ายไฟล์เข้า `online/<รางวัล>/` หรือ `onsite/<รางวัล>/` |
| ไฟล์ PDF ที่วางอยู่ในโฟลเดอร์ online/onsite ตรง ๆ โดยไม่มีโฟลเดอร์รางวัล | สร้างโฟลเดอร์รางวัลแล้วย้ายไฟล์เข้าไป |
| โฟลเดอร์ที่ไม่รู้ว่าเป็นรางวัลอะไร | แก้ชื่อโฟลเดอร์ให้ตรงกับรายชื่อที่หน้าอัปโหลดแสดงไว้ **ระบบไม่เดารางวัลให้** |
| รางวัลที่ไม่มีในรอบนี้ | เช่น Participation ในรอบ Final ให้ตรวจว่าเลือกรอบนำเข้าถูกไหม |
| โฟลเดอร์ online/onsite ซ้อนอยู่ลึกเกินหนึ่งชั้น / มีโฟลเดอร์ครอบชั้นนอกหลายชื่อ | บีบอัดใหม่ให้มีโฟลเดอร์ครอบไม่เกิน 1 ชั้น และใช้ชื่อเดียวกันทั้ง ZIP |
| ไฟล์ที่เป็นเกียรติบัตรของรอบหรือปีอื่น | หยิบไฟล์ผิดรอบ ให้ตรวจไฟล์จากต้นทาง |
| ไฟล์ PDF ที่เปิดไม่ได้ / ไม่มีหน้าเลย | ขอไฟล์ใหม่จากต้นทาง |
| ไม่พบไฟล์ PDF ใน ZIP เลย | บีบอัดผิดไฟล์ (ระบบรับเฉพาะ PDF ไม่รับไฟล์รูป) |

### ตอนอัป PDF รายคน

| ข้อความ | หมายความว่า |
|---|---|
| ชื่อบนเกียรติบัตรตรงกับ ... แล้ว แต่เลขบนหน้าเป็น ... | เลขบนหน้าไม่ตรง ระบบยืนยันตัวคนด้วยเลข เพราะคนชื่อซ้ำกันมีอยู่จริง ให้ขอไฟล์ที่ถูกจากต้นทาง |
| ไฟล์นี้ไม่มีหน้าของผู้เข้าสอบเลข ... — ในไฟล์พบ: ... | หยิบไฟล์ผิดคน ข้อความจะบอกว่าไฟล์นั้นเป็นของใคร |
| ... ระบบแยกไม่ออกว่าหน้าไหนคือใบที่ขาด | ไฟล์มีหน้าของคนนี้หลายใบ ให้แยกใบที่ต้องการออกมาเป็น PDF หน้าเดียวแล้วอัปใหม่ |

ทุกกรณีข้างบนไม่ทำให้ข้อมูลเดิมเสียหาย ระบบตรวจก่อนนำเข้าเสมอ

### ตอนแก้ไข

| ข้อความ | หมายความว่า |
|---|---|
| เผยแพร่อยู่ — ยกเลิกการเผยแพร่ก่อนจึงจะแก้ไขได้ | ข้อ 4 |
| รอให้ระบบประมวลผลเสร็จก่อน | มีงานตัดหน้าหรือจับคู่ค้างอยู่ รอให้เสร็จแล้วค่อยทำต่อ (ปิดหน้าเว็บไปก่อนได้) |
| ข้อมูลนี้ถูกแก้จากที่อื่นไปแล้ว (อาจเปิดไว้หลายแท็บ) | มีคนแก้รายการเดียวกันจากอีกแท็บหรือเครื่องอื่น ให้รีเฟรชแล้วตรวจอีกครั้ง |
| รอบนี้มาจากระบบเดิม — ต้องลบแล้วนำเข้าใหม่ | ข้อ 4 หัวข้อ "รอบที่นำเข้าจากระบบเดิม" |

### กล่องแดง "ประมวลผลล้มเหลว"

จะขึ้นเฉพาะตอน **ระบบพังจริง** ไฟล์ที่ผิดรูปแบบจะไม่ทำให้กล่องนี้ขึ้น
ถ้าเจอ ให้ดู [runbook.md](runbook.md) หรือส่งข้อความในกล่องให้ผู้ดูแลระบบ
งานที่ล้มเหลวกลางทางจะถูกย้อนกลับเอง ไฟล์ที่สร้างไปแล้วบางส่วนจะถูกลบ

## 7. สิ่งที่ห้ามทำ

- **ห้ามเผยแพร่ก่อนตรวจยอด** — ดูยอดทั้งหมด/Online/Onsite ของรายชื่อ และจำนวนที่ถูกค้างไว้ก่อนกดเผยแพร่ทุกครั้ง
- **ห้ามเดาแทนระบบ** — ถ้าไม่แน่ใจว่าหน้านั้นเป็นของใคร ให้ทิ้งหน้าไว้ก่อนแล้วถามต้นทาง ทิ้งแล้วคืนได้ แต่ถ้าเผยแพร่ผิดคนไปแล้วจะเอากลับคืนไม่ได้
- **ห้ามแก้ชื่อตัวคนเพื่อแก้ปัญหาผูกผิดคน** — ให้ใช้ "แยกเป็นคนใหม่"
- **ห้ามส่งไฟล์เกียรติบัตรจริงหรือไฟล์ Excel เข้า git** — เป็นข้อมูลส่วนบุคคล
- **ห้ามแก้เลข `Cert No` บนไฟล์เองเพื่อให้ระบบรับ** — เลขนั้นคือเลขที่พิมพ์อยู่บนเกียรติบัตรฉบับจริงที่เด็กจะได้รับ ให้ขอไฟล์ที่ถูกจากต้นทาง
