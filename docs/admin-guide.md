# คู่มือแอดมิน: การนำเข้าและเพิ่มข้อมูลเกียรติบัตร

คู่มือนี้สำหรับ **คนที่นำเข้าข้อมูลจริง** ไม่ใช่คนเขียนโค้ด
อธิบายว่าเจอสถานการณ์ไหนให้กดปุ่มไหน และข้อความที่ขึ้นแปลว่าอะไร

> รายละเอียดเชิงเทคนิคอยู่ใน [data-intake-spec.md](data-intake-spec.md)
> วิธีแก้เมื่อระบบมีปัญหาอยู่ใน [runbook.md](runbook.md)

---

## หลักการที่ควรรู้ก่อน

ระบบออกแบบบนหลักเดียว: **ถ้าไม่มั่นใจ ระบบจะไม่เดา แต่จะส่งให้คุณตัดสิน**

เพราะการจับคู่ผิดแปลว่าผู้ปกครองดาวน์โหลดเกียรติบัตรของเด็กคนอื่นไป ซึ่งแก้ย้อนหลังไม่ได้
ทุกครั้งที่เห็นระบบถามหรือค้างอะไรไว้ แปลว่ามันเจอสิ่งที่ตัดสินแทนคุณไม่ได้

อีกข้อ: **การเพิ่มข้อมูลไม่เคยลบของเดิม** ยกเว้นปุ่มเดียวที่เขียนเตือนไว้ชัดเจน (ดูท้ายคู่มือ)

## 1. นำเข้าครั้งแรก

### เตรียมไฟล์ 2 อย่าง

**ก. ไฟล์ ZIP เกียรติบัตร** — ข้างในแยกโฟลเดอร์ตามรางวัล

```
HKIMO_Final_2026.zip
 ├── gold/            *.pdf
 ├── silver/          *.pdf
 ├── bronze/          *.pdf
 ├── merit/           *.pdf
 └── perfect score/   *.pdf
```

- ชื่อโฟลเดอร์เขียนได้หลายแบบ `gold` `Gold` `GOLD` `perfect score` `Perfect_Score`
- ชื่อไฟล์ PDF ข้างในไม่สำคัญ ตั้งอะไรก็ได้
- มีโฟลเดอร์ครอบอีกชั้นก็ได้ (เช่น `HKIMO/gold/*.pdf`) ซึ่งเป็นสิ่งที่ได้ตอนอัดโฟลเดอร์ทั้งอัน
- **รางวัลมาจากชื่อโฟลเดอร์เท่านั้น** เพราะหน้า Perfect Score ไม่มีข้อความรางวัลพิมพ์อยู่บนหน้า

**ข. ไฟล์ Excel รายชื่อ** — ต้องมีหัวตารางเหล่านี้

| หัวคอลัมน์ | ใช้ทำอะไร |
|---|---|
| `CANDIDATE NO` | **สำคัญที่สุด** ใช้เป็นคีย์จับคู่หลัก ตรงกับ `Cert No` บนหน้าเกียรติบัตร |
| `CANDIDATE NAME` | ใช้ยืนยันซ้ำว่าเลขไม่ได้ชนกันโดยบังเอิญ |
| `GRADE` | ระดับชั้น |
| `AWARD` | ใช้ตรวจทานกับรางวัลจากโฟลเดอร์ |

### ขั้นตอน

1. **สร้างรายการสอบ** (ทำครั้งเดียวต่อรายการ) — ใส่รหัสสั้น ๆ เช่น `HKIMO`
   รหัสนี้จะไปอยู่ในชื่อไฟล์ทุกใบ
2. **สร้างรอบการนำเข้า** — เลือกรายการสอบ + รอบ (Heat/Final) + ปี ค.ศ.
   - **Heat** = รอบคัดเลือก ผู้เข้าสอบเป็นคนไทยทั้งหมด ระบบตัดทุกหน้า
   - **Final** = รอบชิงชนะเลิศ ไฟล์รวมทุกประเทศ ระบบตัดเฉพาะหน้าที่มี `from THAILAND`

   > **1 รายการสอบ + 1 รอบ + 1 ปี = 1 รอบการนำเข้าเท่านั้น**
   > ถ้าเผลอสร้างซ้ำ ระบบจะเตือนว่ามีอยู่แล้วและมีปุ่มพาไปที่รอบเดิม ไม่สร้างซ้ำให้
   > การเพิ่มไฟล์ทีหลังทำที่รอบเดิมเสมอ ไม่ต้องสร้างรอบใหม่
3. **อัปโหลด ZIP** แล้วรอ ระบบจะตัดหน้า ตั้งชื่อไฟล์ และสร้างรูปตัวอย่าง
4. **อัปโหลด Excel** ระบบจะจับคู่ให้อัตโนมัติ
5. **ตรวจสรุป** (หัวข้อถัดไป)
6. **กดเผยแพร่**

ชื่อไฟล์ที่ได้จะเป็น `{ชื่อ}_{นามสกุล}_{รายการสอบ}_{รอบ}_{รางวัล}_{ปี}.pdf`
เช่น `SOMCHAI_JAIDEE_HKIMO_FINAL_GOLD_2026.pdf`

## 2. อ่านหน้าสรุปให้เป็น

ตัวเลขที่ควรดูก่อนเผยแพร่

| หัวข้อ | ควรเป็นเท่าไร |
|---|---|
| ตัดแยกแล้ว | เท่ากับจำนวนหน้าในไฟล์จริง (หัก "ข้าม (ไม่ใช่คนไทย)" ออก) |
| อ่านชื่อไม่ออก | **0** ถ้าไม่ใช่ 0 แปลว่าแบบฟอร์มต่างจากที่ระบบรู้จัก |
| รางวัลบนหน้าไม่ตรงโฟลเดอร์ | **0** ถ้าไม่ใช่ 0 แปลว่ามีไฟล์วางผิดโฟลเดอร์ |
| จับคู่สำเร็จ | เท่ากับจำนวนหน้าที่ตัดได้ |
| ยังไม่มีคู่ / ชื่อซ้ำ รอตัดสิน | **0** ถ้าไม่ใช่ 0 ต้องจัดการก่อน |
| รางวัลไม่ตรงกับ Excel | ไม่ใช่ 0 ได้ ถ้าใกล้เคียงจำนวนคนที่ได้ Perfect Score (อธิบายด้านล่าง) |

### ทำไม "รางวัลไม่ตรงกับ Excel" ไม่เป็น 0 ถึงปกติ

Perfect Score เป็นรางวัลเสริมที่ให้คนได้เหรียญทองซึ่งทำคะแนนได้ดี
คนกลุ่มนี้มีเกียรติบัตร 2 ใบ (Gold + Perfect Score) แต่ **Excel มีแถวเดียวเขียนว่า `PERFECT SCORER`**
ใบ Gold ของพวกเขาจึง "ไม่ตรง" กับ Excel อย่างถูกต้อง

แต่ถ้าตัวเลขนี้สูงกว่าจำนวน Perfect Scorer มาก ให้กลับไปตรวจว่าจัดไฟล์เข้าโฟลเดอร์ถูกไหม

## 3. เพิ่มข้อมูลทีหลัง — เลือกวิธีให้ถูก

ต้นทางส่งของมาไม่ครบเป็นเรื่องปกติ ระบบรองรับการเติมทีหลังโดยไม่ต้องทำใหม่ทั้งรอบ

| สถานการณ์ | ใช้วิธี | อยู่ตรงไหน |
|---|---|---|
| ตกหล่นไม่กี่คน ได้ไฟล์มาทีละใบ | **โยน PDF ในบล็อกของคนนั้น** | หัวข้อ "รายการที่ต้องตามเก็บ" |
| ต้นทางส่งชุดใหม่มาทั้งก้อน | **อัป ZIP เติม** | ขั้นที่ 1 ปุ่ม "เลือกไฟล์ ZIP ที่มีเกียรติบัตรตกหล่น" |
| รายชื่อ Excel ผิดหรือไม่ครบ | **อัป Excel ใหม่ทับ** | ขั้นที่ 2 |
| ไฟล์ชุดเดิมผิดทั้งชุด | **ตัดใหม่ทั้งรอบ** ⚠️ | ขั้นที่ 1 ลิงก์เล็กด้านล่าง |

### 3.1 โยน PDF ทีละใบ (ใช้บ่อยที่สุด)

หลังประมวลผลจบ ระบบจะรวมคนที่มีปัญหาไว้ในหัวข้อ **"รายการที่ต้องตามเก็บ"** เป็นบล็อกรายคน

```
┌────────────────────────────────────────────────┐
│ PUTTHITHADA ARNON              เลข 203336       │
│ มีใบ Perfect Score แต่ไม่มีใบเหรียญ                │
│ ไฟล์ที่ขาด: เหรียญทอง                             │
│                                                │
│ [   เลือกไฟล์ PDF ที่ได้มาใหม่   ]                 │
└────────────────────────────────────────────────┘
```

พอได้ไฟล์จากต้นทาง **โยน PDF เข้าไปในบล็อกนั้นตรง ๆ**
ไม่ต้องสร้างโฟลเดอร์ ไม่ต้องอัด ZIP ไม่ต้องเลือกรางวัล

ระบบจะ:
1. ตรวจว่าเลขบนหน้าตรงกับคนในบล็อกนั้นจริง
2. ตั้งชื่อไฟล์ให้เหมือนคนอื่น
3. สร้างรูปตัวอย่าง
4. จับคู่ให้ แล้วบล็อกนั้นหายไป
5. ขึ้นปุ่ม **"เผยแพร่เพิ่ม N ใบ"** ให้กด

**ไฟล์รวมเล่มก็โยนเข้ามาได้** ต้นทางมักส่งกลับมาเป็นไฟล์เดียวหลายสิบหน้า ไม่ได้แยกหน้าให้
ไม่ต้องไปตัดหน้าเอง ระบบจะ **คัดเฉพาะหน้าของคนในบล็อกนั้นออกมาใบเดียว** โดยดูจากเลขบนหน้า
แล้วขึ้นบอกว่าใช้หน้าไหน เช่น *"ไฟล์ที่อัปมามี 62 หน้า ระบบใช้เฉพาะหน้าที่ 1 ..."*
หน้าของคนอื่นในไฟล์นั้น **ไม่ถูกนำเข้า** — ถ้าตกหล่นหลายคน ให้โยนไฟล์เดียวกันนี้ในบล็อกของแต่ละคน
หรือใช้วิธีอัป ZIP เติม (ข้อ 3.2) ซึ่งเร็วกว่าเมื่อมีหลายคน

**รายการนี้มี 2 แบบ**

| ขึ้นว่า | แปลว่า | ไฟล์ที่ขาด |
|---|---|---|
| มีชื่อในรายชื่อ Excel แต่ไม่มีหน้าเกียรติบัตรเลย | ต้นทางไม่ได้ส่งเกียรติบัตรของคนนี้มา | รางวัลตามที่ Excel บอก |
| มีใบ Perfect Score แต่ไม่มีใบเหรียญ | ใบเหรียญตกหล่น (เป็นไปไม่ได้ตามกติกาการให้รางวัล) | เหรียญทอง |

### 3.2 อัป ZIP เติม

ใช้ตอนต้นทางส่งชุดใหม่มาทั้งก้อน หรือตกหล่นหลายคนจนโยนทีละใบไม่ไหว

**อัด ZIP ชุดเต็มทั้งก้อนแล้วโยนเข้าไปได้เลย** ไม่ต้องคัดว่าใบไหนใหม่
ระบบจะเติมเฉพาะใบที่ยังไม่มี แล้วรายงานว่าข้ามไปกี่ใบ

เผลออัปไฟล์เดิมซ้ำก็ไม่เกิดอะไรขึ้น หน้าที่มีอยู่แล้วไม่ถูกแตะ

> ตรวจของซ้ำด้วย **เลขผู้เข้าสอบคู่กับรางวัล**
> คนเดียวกันที่ได้คนละรางวัลจึงเติมเข้าไปได้ ไม่ถูกมองว่าซ้ำ

### 3.3 อัป Excel ใหม่

อัปทับได้เลย ระบบจะจับคู่ใหม่ทั้งรอบจากรายชื่อฉบับล่าสุด
**สิ่งที่คุณจับคู่ด้วยมือหรือตัดสินไปแล้วจะไม่ถูกลบ**

### 3.4 ⚠️ ตัดใหม่ทั้งรอบ

ปุ่มนี้ซ่อนไว้ใต้ลิงก์เล็ก ๆ และต้องยืนยันก่อน เพราะมัน **ลบหน้าที่นำเข้าไปแล้วทั้งหมดของรอบนั้นทิ้ง**
รวมถึงเกียรติบัตรที่เผยแพร่ไปแล้วและที่คุณจับคู่ด้วยมือไว้

ใช้เฉพาะตอนไฟล์ชุดเดิมผิดทั้งชุดเท่านั้น **ถ้าแค่จะเติมของที่ขาด อย่าใช้ปุ่มนี้**

## 4. การเผยแพร่

### เผยแพร่ทีละคน ไม่ใช่ทั้งรอบ

คนที่ข้อมูลครบจะออกไปก่อน ส่วนคนที่ยังมีปัญหาจะ **ค้างไว้ในระบบ** ไม่หลุดออกไป
คุณจึงเปิดให้ผู้ปกครองใช้ได้เลยโดยไม่ต้องรอจนครบทุกคน

พอเติมไฟล์ที่ขาดแล้ว กด **"เผยแพร่เพิ่ม N ใบ"** คนที่พร้อมแล้วจะตามออกไป

### ต้องเลือกก่อนเผยแพร่: ฮ่องกงส่งฉบับจริงมาแบบไหน

รอบที่มีคนถือทั้งใบเหรียญและใบ Perfect Score ระบบจะถามก่อน

| ตัวเลือก | ผล |
|---|---|
| ทั้งสองใบ | ผู้ปกครองเห็นทั้งใบเหรียญและใบ Perfect Score |
| เฉพาะใบเหรียญ | เห็นแค่ใบเหรียญ ใบ Perfect Score ถูกซ่อน (ไม่ได้ลบ) |

เลือกผิดแก้ได้ตลอด กดเลือกใหม่แล้วระบบปรับให้ทันที
ตัวเลือกนี้ขึ้นเฉพาะรอบที่มีเคสนี้จริง รอบอื่นกดเผยแพร่ได้เลย

## 5. ข้อความที่อาจเจอ แปลว่าอะไร

### ตอนอัป ZIP

| ข้อความ | ทำอะไรต่อ |
|---|---|
| โฟลเดอร์ที่ไม่รู้ว่าเป็นรางวัลอะไร: ... | แก้ชื่อโฟลเดอร์ใน ZIP ให้เป็น gold/silver/bronze/merit/perfect score แล้วอัดใหม่ |
| ไฟล์ PDF ที่วางอยู่นอกโฟลเดอร์รางวัล | ย้าย PDF เข้าโฟลเดอร์รางวัลก่อน |
| ไม่พบไฟล์ PDF ใน ZIP เลย | อัดผิดไฟล์ |

### ตอนโยน PDF ทีละใบ

ข้อความจะขึ้น **ในช่องอัปโหลดของคนนั้นที่เดียว** และอยู่ถาวรจนกว่าจะอัปใหม่

| ข้อความ | แปลว่า |
|---|---|
| ชื่อบนเกียรติบัตรตรงกับ ... แล้ว แต่เลขบนหน้าเป็น ... ต้องเป็น ... | แก้ไฟล์เองแล้วเปลี่ยนแค่ชื่อ ลืมแก้บรรทัด `Cert No` — ระบบยืนยันตัวคนด้วยเลข ไม่ใช่ชื่อ เพราะคนชื่อพ้องกันมีจริง |
| ไฟล์นี้ไม่มีหน้าของผู้เข้าสอบเลข ... — ในไฟล์พบ: ... | หยิบไฟล์ผิดคน ข้อความจะบอกว่าไฟล์นั้นเป็นของใคร (ถ้าเป็นไฟล์รวมเล่ม จะยกตัวอย่าง 5 คนแรกแล้วบอกว่ามีอีกกี่หน้า) |
| ไฟล์นี้มีหน้าของเลข ... อยู่ 2 หน้า ... ระบบแยกไม่ออกว่าหน้าไหนคือใบที่ขาด | ในไฟล์มีของคนนี้หลายใบและบอกไม่ได้ว่าใบไหนคือใบที่ขาด — แยกใบที่ขาดออกมาเป็นไฟล์ PDF หน้าเดียวแล้วอัปใหม่ (ระบบไม่เดา เพราะเดาผิดแปลว่ารางวัลบนหน้าเว็บผิด) |

**ทั้งสองแบบไม่มีอะไรเสียหาย** ระบบตรวจก่อนลงมือประมวลผล ของเดิมไม่ถูกแตะเลย

### อายุการเก็บ 2 ปี

เกียรติบัตรถูกเก็บไว้ **2 ปีนับจากวันเผยแพร่** หลังจากนั้นระบบจะลบไฟล์ออกจากคลาวด์
ผู้ปกครองจะค้นไม่เจอ แต่ข้อมูลว่าใครได้รางวัลอะไรยังอยู่ในระบบ

- หน้ารอบนำเข้าบอกไว้ตั้งแต่แรกว่า "เกียรติบัตร N ใบของรอบนี้จะถูกลบไฟล์วันที่ ..."
- ถ้ามีคนขอให้เก็บต่อ กด **"ต่ออายุอีก 1 ปี"** ที่รอบนั้นได้
- หน้ารวมจะเตือนล่วงหน้า 30 วัน พร้อมปุ่ม **"ลองดูว่าจะลบอะไรบ้าง"** ที่ไม่ลบจริง
- หน้าค้นหาของผู้ปกครองมีข้อความแจ้งนโยบายนี้อยู่ท้ายรายการของแต่ละคน

การลบจริงถูก**ปิดไว้เป็นค่าตั้งต้น** เปิดโดยตั้ง `RETENTION_ENABLED=true` ที่ service `worker`

### ลบรอบการนำเข้าทั้งรอบ

อยู่ท้ายหน้ารอบนำเข้า ในกรอบแดง **"โซนอันตราย"**

ใช้เมื่อต้องการให้รอบนั้นหายไปทั้งหมดจริง ๆ เช่นสร้างผิดปี ผิดรอบ หรืออยากนำเข้าใหม่ทั้งชุด
**ถ้าแค่อยากนำเข้าไฟล์ชุดใหม่ทับของเดิม ใช้ "ตัดใหม่ทั้งรอบ" พอ** ไม่ต้องลบ

ก่อนลบจะบอกก่อนว่าจะหายไปแค่ไหน แล้ว**ต้องพิมพ์ชื่อรอบยืนยัน** เช่น `HKIMO FINAL 2026`
ถ้ารอบนั้นเผยแพร่อยู่ ต้องติ๊กเพิ่มอีกช่องว่าเข้าใจว่าผู้ปกครองจะค้นไม่เจอทันที

| สิ่งที่หายไป | สิ่งที่ไม่หาย |
|---|---|
| เกียรติบัตร รูปตัวอย่าง และไฟล์ต้นฉบับของรอบนั้นทั้งหมด | รายการสอบและรอบการสอบ (สร้างรอบนำเข้าใหม่ได้เลย) |
| ข้อมูลการจับคู่ทั้งหมดของรอบนั้น | ผู้เข้าสอบที่ยังมีเกียรติบัตรจากรอบอื่น |

**กู้คืนไม่ได้** ถ้าต้องการข้อมูลกลับมาต้องนำเข้าใหม่จากไฟล์ต้นฉบับในเครื่องตัวเอง

### ไฟล์ต้นฉบับ (ZIP) หายไปเอง — ปกติ

หลังเผยแพร่และจับคู่ครบทุกคน ระบบจะ**ลบไฟล์ ZIP ที่อัปเข้ามาทิ้งอัตโนมัติ**
เพราะไฟล์นั้นใหญ่มาก (หลายร้อย MB) และไม่มีอะไรในระบบเรียกใช้อีกแล้ว
เกียรติบัตร รูปตัวอย่าง และไฟล์รายชื่อ (Excel) ยังอยู่ครบเหมือนเดิม

ดูสถานะได้ที่หัวข้อ **"ไฟล์ต้นฉบับ"** ท้ายหน้ารอบนำเข้า ถ้ายังไม่เคลียร์จะบอกว่าติดเงื่อนไขข้อไหน

ถ้าต้องตัดหน้าใหม่จากต้นฉบับหลังไฟล์ถูกลบไปแล้ว ให้อัป ZIP ขึ้นมาใหม่จากเครื่องตัวเอง

### ตอนจับคู่

| หัวข้อ | ต้องทำอะไร |
|---|---|
| หน้าที่ยังจับคู่ไม่ได้ | กรอกชื่อจับคู่ด้วยมือ (กรอกโรงเรียนด้วยจะช่วยรอบหน้า) |
| ชื่อซ้ำ ต้องตัดสิน | เทียบเกียรติบัตรทั้งสองใบแล้วเลือกว่าเป็นคนละคน หรือเป็นใบซ้ำ |
| มีผู้เข้าสอบชื่อนี้อยู่ในระบบมากกว่าหนึ่งคน | จับคู่ด้วยมือและ **กรอกโรงเรียน** รอบหน้าระบบจะแยกได้เอง |

### กล่องแดง "ประมวลผลล้มเหลว"

ขึ้นเฉพาะตอน **ระบบพังจริง** เท่านั้น ไฟล์ที่อัปไม่ถูกจะไม่ทำให้กล่องนี้ขึ้น
ถ้าเจอ ให้ดู [runbook.md](runbook.md) หรือส่งข้อความให้ผู้ดูแลระบบ

## 6. สิ่งที่ห้ามทำ

- **ห้ามกด "ตัดใหม่ทั้งรอบ" เพื่อเติมไฟล์ที่ขาด** — ใช้ปุ่มเติมแทน
- **ห้ามเผยแพร่ก่อนตรวจยอด** — จับคู่ผิดแล้วเผยแพร่ แก้ย้อนหลังไม่ได้
- **ห้ามส่งไฟล์เกียรติบัตรจริงหรือไฟล์ Excel เข้า git** — เป็นข้อมูลส่วนบุคคล
- **ห้ามแก้เลข `Cert No` บนหน้ากระดาษให้ตรงเฉย ๆ เพื่อให้ระบบรับไฟล์** — เลขนั้นคือสิ่งที่พิมพ์
  อยู่บนฉบับจริงที่เด็กจะได้รับ ถ้าไม่ตรงกันจะสับสนภายหลัง ควรขอไฟล์ที่ถูกต้องจากต้นทาง
