# คู่มือแก้ปัญหา

## ต้นทางส่งเกียรติบัตรมาไม่ครบ แล้วส่งตามมาทีหลัง

เกิดบ่อยที่สุด วิธีทำคือ **เติมเข้ารอบนำเข้าเดิม ไม่ใช่สร้างรอบใหม่**

### 1. หาว่าใครตกหล่น

เปิดหน้า batch ดูหัวข้อ **"รายชื่อใน Excel ที่ไม่มีหน้าเกียรติบัตร"**
จะได้เลขผู้เข้าสอบและชื่อครบ ใช้รายการนี้แจ้งกลับไปที่ต้นทางได้เลย

> ถ้าเป็นกรณีคนเดียวได้หลายรางวัลแล้วขาดไปบางใบ (เช่นได้ทั้ง Gold และ Perfect Score
> แต่ต้นทางส่งมาแค่ Perfect Score) รายการนี้จะไม่ขึ้น เพราะ Excel มีแถวเดียวต่อคน
> ให้ตรวจด้วยการนับจำนวนหน้าต่อรางวัลเทียบกับที่ต้นทางแจ้งมาแทน

### 2. พอได้ไฟล์มาแล้ว

**ถ้าตกหล่นไม่กี่คน — โยน PDF เข้าไปในบล็อกของคนนั้นได้เลย**

หัวข้อ **"รายการที่ต้องตามเก็บ"** จะมีบล็อกของแต่ละคนพร้อมชื่อ เลขผู้เข้าสอบ
และบอกว่าไฟล์ที่ขาดคือรางวัลอะไร กดเลือกไฟล์ PDF ในบล็อกนั้นได้เลย
ไม่ต้องสร้างโฟลเดอร์ ไม่ต้องอัด ZIP ไม่ต้องเลือกรางวัล

ระบบจะตั้งชื่อไฟล์ให้เหมือนคนอื่น สร้างรูปตัวอย่าง และจับคู่ให้เอง
**และจะตรวจก่อนว่าไฟล์เป็นของคนนั้นจริง** ถ้าหยิบไฟล์ผิดคนจะไม่รับ
พร้อมบอกว่าไฟล์นั้นเป็นของใคร — ของที่นำเข้าไปแล้วไม่ถูกแตะ

**ถ้าต้นทางส่งชุดใหม่มาทั้งก้อน** ใช้ปุ่ม **"เลือกไฟล์ ZIP ที่มีเกียรติบัตรตกหล่น"**
ในขั้นที่ 1 แทน (ไม่ใช่ปุ่ม "ตัดใหม่ทั้งรอบ")

- หน้าที่นำเข้าไปแล้วจะไม่ถูกแตะเลย
- ระบบเติมเฉพาะใบที่ยังไม่มี โดยดูจาก **เลขผู้เข้าสอบคู่กับรางวัล**
  คนเดียวกันที่ได้คนละรางวัลจึงเติมเข้าไปได้ ไม่โดนมองว่าซ้ำ
- จะอัป **ZIP ชุดเต็มทั้งก้อน** ก็ได้ ไม่ต้องแยกไฟล์ทีละใบ
  ระบบจะข้ามของที่มีอยู่แล้วให้เอง และรายงานว่าข้ามไปกี่ใบ
- ถ้าเคยนำเข้ารายชื่อ Excel ไว้แล้ว ระบบจะจับคู่ต่อให้อัตโนมัติ ไม่ต้องอัป Excel ซ้ำ

### 3. ตรวจผล

ดูสถิติว่า `ตัดแยกแล้ว` เพิ่มขึ้นตามจำนวนที่ควรได้ และ `ข้ามเพราะมีอยู่แล้ว` สมเหตุสมผล
แล้วดูว่า `รายชื่อใน Excel ที่ไม่มีหน้าเกียรติบัตร` ลดลงหรือหมดไป

### ⚠️ อย่ากด "ตัดใหม่ทั้งรอบ" ถ้าแค่จะเติมไฟล์

ปุ่มนั้นจะ **ลบหน้าที่นำเข้าไปแล้วทั้งหมดของรอบนั้นทิ้ง** รวมถึงเกียรติบัตรที่ออกไปแล้ว
และที่จับคู่ด้วยมือไว้ ใช้เฉพาะตอนไฟล์ชุดเดิมผิดทั้งชุดเท่านั้น

## อัปไฟล์ของคนที่ตกหล่นแล้วระบบไม่รับ

ข้อความจะขึ้นในบล็อกของคนนั้นเลย ขึ้นว่า "ไม่รับไฟล์นี้ — ..." มี 2 แบบ

**แบบที่ 1: "ชื่อบนเกียรติบัตรตรงกับ ... แล้ว แต่เลขบนหน้าเป็น ... ต้องเป็น ..."**

เจอบ่อยตอนแก้ไฟล์เอง — เปลี่ยนชื่อนักเรียนแล้วแต่ลืมแก้บรรทัด `Cert No`
ระบบยืนยันตัวคนด้วยเลข ไม่ใช่ชื่อ เพราะคนชื่อพ้องกันมีจริง
ให้กลับไปแก้บรรทัด `Cert No` บนหน้ากระดาษให้เป็นเลขที่ระบบบอก แล้วอัปใหม่

**แบบที่ 2: "ไฟล์นี้ไม่มีหน้าของผู้เข้าสอบเลข ..."**

หยิบไฟล์ผิดคน ข้อความจะบอกว่าในไฟล์พบเลขและชื่อของใคร

**ทั้งสองแบบไม่มีอะไรเสียหาย** ระบบตรวจก่อนลงมือประมวลผล จึงไม่มีไฟล์ขยะค้าง
ไม่แตะของเดิม สถานะรอบไม่เปลี่ยน และของที่เผยแพร่ไปแล้วยังใช้งานได้ตามปกติ

หน้า batch จะขึ้นกล่อง**สีเหลือง** "ไฟล์ที่อัปล่าสุดยังไม่ถูกรับ" ค้างไว้จนกว่าจะอัปไฟล์ใหม่
ไม่ใช่กล่องแดง "ประมวลผลล้มเหลว" ซึ่งสงวนไว้สำหรับตอนระบบพังจริงเท่านั้น

## เผยแพร่ไม่ได้ ระบบบอกให้เลือกก่อน

รอบที่มีผู้เข้าสอบถือทั้งใบเหรียญและใบ Perfect Score ต้องบอกระบบก่อนว่า
**ฮ่องกงส่งเกียรติบัตรฉบับจริงมาแบบไหนสำหรับรอบนั้น**

- **ทั้งสองใบ** — ผู้ปกครองเห็นทั้งใบเหรียญและใบ Perfect Score
- **เฉพาะใบเหรียญ** — เห็นแค่ใบเหรียญ ใบ Perfect Score ถูกซ่อน (ยังอยู่ในระบบ ไม่ได้ลบ)

เลือกผิดแก้ได้ตลอด กดเลือกใหม่แล้วระบบปรับให้ทันทีถ้ารอบนั้นเผยแพร่ไปแล้ว

> Perfect Score เป็นรางวัลเสริมที่ให้คนได้เหรียญทองซึ่งทำคะแนนได้ดี
> ระบบเดาแทนไม่ได้ว่ารอบไหนส่งฉบับจริงมาแบบไหน จึงต้องถามก่อนเผยแพร่

## บางคนไม่ถูกเผยแพร่ ขึ้นว่า "ค้างไว้เพราะข้อมูลไม่ครบ"

ระบบเผยแพร่ **ทีละคน** คนที่ข้อมูลครบออกไปก่อน ส่วนคนที่ยังมีปัญหาค้างไว้
เพื่อให้ไม่ต้องรอจนครบทุกคนถึงจะเปิดให้ผู้ปกครองใช้ได้

ตอนนี้มีเงื่อนไขการค้างข้อเดียว: **มีใบ Perfect Score แต่ไม่มีใบเหรียญ**

เป็นไปไม่ได้ตามกติกาการให้รางวัล (Perfect Score ให้เฉพาะคนที่ได้เหรียญทอง)
แปลว่าไฟล์ใบเหรียญของคนนั้นตกหล่น ระบบจึงกันไว้ทั้งคน ไม่ปล่อยใบ Perfect Score
ออกไปแทนใบที่ผู้ปกครองควรได้จริง

**วิธีแก้:** ขอไฟล์ใบเหรียญจากต้นทาง แล้วโยน PDF เข้าไปในบล็อกของคนนั้น
ที่หัวข้อ "รายการที่ต้องตามเก็บ" จากนั้นกด **"เผยแพร่เพิ่ม N ใบ"** ที่จะขึ้นมาให้

## ผู้ปกครองบอกว่าค้นชื่อไม่เจอ

ไล่ตามลำดับนี้:

1. **batch เผยแพร่แล้วหรือยัง** — หน้าแอดมินต้องขึ้นสถานะ "เผยแพร่แล้ว"
   ถ้ายังไม่เผยแพร่ ผู้ใช้จะค้นไม่เจอแม้ข้อมูลจะถูกต้องครบ
1.1 **คนนั้นถูกค้างไว้หรือเปล่า** — ดูหัวข้อ "ค้างไว้เพราะข้อมูลไม่ครบ" ในหน้า batch
   และถ้าเป็นใบ Perfect Score ให้ดูด้วยว่ารอบนั้นตั้งไว้ว่าเผยแพร่เฉพาะใบเหรียญหรือไม่
2. **หน้านั้นจับคู่ได้ไหม** — เปิดหน้า batch ดูส่วน "หน้าที่ยังจับคู่ไม่ได้"
3. **ชื่อในระบบสะกดตรงกับที่ผู้ปกครองพิมพ์ไหม**
   ```sql
   SELECT name_th, name_en, name_th_normalized, name_en_normalized
   FROM students WHERE name_th_normalized LIKE '%สมชาย%';
   ```
   ถ้า normalized ว่างหรือหน้าตาแปลก แสดงว่ามีอักขระที่กฎ normalize จัดการไม่ได้

## งานค้างอยู่ที่ "กำลังประมวลผล" ไม่ขยับ

```sql
SELECT id, type, status, attempts, error, locked_at FROM jobs ORDER BY created_at DESC LIMIT 5;
```

- **status = QUEUED นาน** → worker ไม่ได้ทำงาน ดู `docker compose logs worker` หรือ log ของ Railway
- **status = RUNNING แต่ `locked_at` เก่ามาก** → worker ตายกลางทาง
  ปลดล็อกด้วยการสั่งให้กลับเข้าคิว:
  ```sql
  UPDATE jobs SET status = 'QUEUED', locked_at = NULL
  WHERE id = '<job id>' AND status = 'RUNNING';
  ```
- **status = FAILED** → อ่านคอลัมน์ `error` มี traceback เต็ม

## จับคู่ผิดคน (เรื่องด่วน)

1. **ยกเลิกการเผยแพร่ batch นั้นทันที** จากหน้าแอดมิน — หยุดไม่ให้โหลดต่อได้ก่อน
2. แก้ไฟล์ Excel ให้ถูก แล้วอัปโหลดใหม่ (ระบบจับคู่ใหม่ทับของเดิมให้เอง ไม่ต้องตัด PDF ใหม่)
3. ตรวจหน้าสรุปให้ตัวเลขตรงก่อนเผยแพร่อีกครั้ง

## อัปโหลด ZIP แล้ว job ล้มเหลวทันที

อ่านข้อความ error ในหน้า batch จะบอกตรง ๆ ว่าเจออะไร กรณีที่พบบ่อย:

- **"โฟลเดอร์ที่ไม่รู้ว่าเป็นรางวัลอะไร"** → ชื่อโฟลเดอร์ใน ZIP สะกดไม่ตรง
  ที่รองรับคือ gold / silver / bronze / merit / perfect score (ตัวพิมพ์เล็กใหญ่ไม่สำคัญ
  ใช้ `_` หรือเว้นวรรคก็ได้) ให้แก้ชื่อโฟลเดอร์แล้วบีบ ZIP ใหม่
- **"ไฟล์ PDF ที่วางอยู่นอกโฟลเดอร์รางวัล"** → มี PDF วางไว้ที่ชั้นบนสุด ต้องย้ายเข้าโฟลเดอร์รางวัล
- **"ไม่พบไฟล์ PDF ใน ZIP เลย"** → บีบผิดไฟล์ หรือบีบเป็นนามสกุลอื่นที่ไม่ใช่ .zip

ระบบตั้งใจหยุดทั้งงานแทนที่จะเดารางวัลให้ เพราะรางวัลผิดจะไปโผล่บนหน้าเว็บของเด็ก

## ตัดหน้าแล้วได้จำนวนไม่ตรงกับไฟล์

ดูค่าในหน้าสรุปของ batch:

- `ข้าม (ไม่ใช่คนไทย)` สูงผิดปกติ → เลือกรอบผิด (รอบ Heat ไม่ควรข้ามเลย)
  หรือ regex ตรวจสัญชาติไม่ตรงกับไฟล์ ตั้ง env `NATIONALITY_PATTERN` ใหม่
- `อ่านชื่อไม่ออก` สูง → แบบฟอร์มของรายการสอบนี้ต่างจากที่ตั้งค่าไว้
  รันสำรวจด้วย `docker compose exec worker python scripts/check_real_files.py`
  แล้วปรับ env ตาม `docs/pdf-parsing-notes.md`
- `รางวัลบนหน้าไม่ตรงโฟลเดอร์` ไม่เป็น 0 → มีไฟล์วางผิดโฟลเดอร์ ให้ตรวจ ZIP ต้นทาง
- ทุกค่าปกติแต่จำนวนหน้ายังไม่ตรง → ไฟล์ PDF อาจเสียบางหน้า

## `รางวัลไม่ตรงกับ Excel` ไม่เป็น 0 — ผิดไหม

**ไม่ผิดเสมอไป** ของจริงผู้ที่ได้ `PERFECT SCORER` จะมีใบ Gold ด้วย
แต่ Excel บันทึกให้แค่แถวเดียวว่า PERFECT SCORER ทำให้ใบ Gold "ไม่ตรง" อย่างถูกต้อง

ให้ดูว่าตัวเลขนี้ใกล้เคียงกับจำนวน Perfect Scorer ไหม ถ้าสูงกว่านั้นมาก
แปลว่ามีไฟล์วางผิดโฟลเดอร์ หรือใช้ Excel ผิดรอบ

## หน้าขึ้นว่า "มีผู้เข้าสอบชื่อนี้อยู่ในระบบมากกว่าหนึ่งคน"

ระบบเจอคนชื่อพ้องกันในฐานข้อมูลและแยกไม่ออกว่าเป็นคนไหน จึงไม่เดาให้

แก้โดยจับคู่ด้วยมือในหน้า batch แล้ว **กรอกโรงเรียนด้วย**
รอบถัดไประบบจะใช้โรงเรียนแยกคนได้เองโดยไม่ต้องถามอีก

## ผู้ใช้กดดาวน์โหลดแล้วได้ Access Denied

presigned URL มีอายุ 15 นาที ถ้าผู้ใช้เปิดหน้าค้างไว้นานแล้วค่อยกด ให้รีเฟรชหน้าใหม่
ถ้าเกิดกับทุกคนทันทีที่กด แปลว่า credential ของ R2 ผิดหรือหมดอายุ

## ต้องลบข้อมูลของ batch ทิ้งทั้งรอบ

```sql
-- certificates และ staging_pages ถูกลบตามด้วย ON DELETE CASCADE
DELETE FROM batches WHERE id = '<batch id>';
```
ไฟล์บน R2 **ไม่ถูกลบตาม** ต้องลบเองจาก Cloudflare dashboard ที่ prefix
`certificates/<batch id>/`, `previews/<batch id>/` และ `sources/<batch id>/`

> ZIP ต้นฉบับใน `sources/` มีขนาดหลายร้อย MB ต่อรอบ
> ถ้าพื้นที่ใกล้เต็ม ให้ลบเฉพาะ `sources/` ของรอบที่ยืนยันแล้วว่านำเข้าถูกต้อง
> แต่ต้องมั่นใจก่อนว่าสำรองฐานข้อมูลไว้แล้ว

## ตรวจว่าระบบยังรับโหลดได้ไหม

```bash
BASE_URL=https://<โดเมนจริง> k6 run scripts/loadtest.js
```
เกณฑ์ผ่าน: p95 < 500ms, error rate < 1%
ถ้าไม่ผ่าน จุดแรกที่ต้องดูคือ index trigram บนตาราง `students` ยังอยู่ครบไหม:
```sql
SELECT indexname FROM pg_indexes WHERE tablename = 'students';
```
